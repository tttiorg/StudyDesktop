# 学习桌面 · Study Desktop

一个跑在本地的个人学习工作台：课表、成绩、学科资料、日程待办集中在一个界面里，双击就能用，数据全部存在自己的硬盘上。

不依赖任何云服务，不需要注册账号，关掉网页数据依然在。

## 功能

- **课表**：周视图，随时点格子改课；今天的课自动高亮
- **日程待办**：作业、考试、任务按日期分组，逾期会标出来
- **学科空间**：每门课一页，左侧成绩、中间知识点与笔记、右侧任务与资料
- **成绩管理**：按得分率自动配色（不及格 / 及格 / 优秀）
- **资料文件**：把本地文件或整个文件夹映射进来，按学科归类，可上传副本也可只建映射（不动原文件）
- **外链速达**：右侧图标栏放常用网站，图标自动抓取，可拖动排序
- **News 侧栏**：左侧抽屉，展开时内容区自动让位
- **启动转场**：带进度与品牌动画的开场
- **数据导入**：一份 JSON 描述你的课程与成绩，AI 帮你填好后一键导入

## 快速开始

### Windows

双击 **`启动.vbs`** —— 静默启动，不弹终端窗口，直接用全屏应用窗口打开。

需要排查问题就双击 **`启动.bat`**，它会显示完整的安装与构建日志。

首次运行会自动安装依赖并构建前端，需要几分钟，之后秒开。

### 手动启动

```bash
npm install
npm run build
npm run server      # 打开 http://localhost:3001
```

### 开发模式

```bash
npm run dev
# 前端 http://localhost:5173（热更新），后端 3001
```

## 数据存在哪

默认 `D:\Document\学习桌面`（没有 D 盘时退回 `文档\学习桌面`），结构是：

```
学习桌面/
├── db/          # 各种 json，就是你的全部数据
├── files/       # 资料实体文件
└── backups/     # 自动备份，会定期清理过期份
```

想换位置，改项目根目录的 `config.json`：

```json
{
  "dataDir": "E:\\我的学习数据",
  "port": 3001
}
```

也可以用环境变量 `STUDY_DATA_DIR` 和 `STUDY_PORT` 覆盖。

**整个目录拷走就等于完整备份**，换台电脑放回去就能继续用。

## 导入自己的数据

`web/public/data-format/` 下有两份东西：

- `README.md` —— 完整的数据格式规范
- `study-desktop.template.json` —— 空模板

把模板交给 AI，让它按规范把你的课表、成绩填进去，然后点顶栏的 **导入** 按钮，选择或直接拖入该文件即可。合并或覆盖都行，导入过程会一步步打印结果。

## 目录结构

```
server/            Express 后端
├── api/           各个数据接口（学科、课表、成绩、文件、导入…）
├── store.js       json 读写 + 自动备份
└── config.js      数据目录与端口

web/               Vue 3 前端
├── src/views/     页面：主页、课表、学科
├── src/components/
├── src/styles/    主题 + 启动转场
└── public/        图标、数据格式文档

electron/          可选的桌面版外壳
scripts/           开发脚本
启动.vbs / 启动.bat
```

## 技术栈

Vue 3（`<script setup>`）· Vite · Pinia · Vue Router · Element Plus · Express · Electron（可选）

后端只用了 Express + 文件系统，没有数据库。所有数据是可直接阅读的 json，出问题能手工修。

## 一点说明

- **默认外链是某所大学的校内系统**（教务、图书馆、Blackboard 等）。**右键点图标**就能改成自己的网址，也可以整套删掉重加。
- **教师信息查询**对接的是那所大学的公开师资库，别的学校用不了，可以忽略这个入口。
- 启动转场每次启动播一次，切换页面不会重播。
